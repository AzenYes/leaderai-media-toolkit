# 文案与封面：每次交付成片都要附带

每支片交付时，除 mp4 外必须附带 **一份文案文档 + 两张 4K 封面**（都用代码绘制，和成片同一套字体、色彩、发光语言）。模板：`assets/starter/copy_template.md`（`new_film.mjs` 已复制到 `work/文案与封面.md`）；封面源码：`film/cover.html`；渲染：`scripts/cover.mjs`。

## 1. 文案文档（`out/<名称>_文案与封面.md`）

内容固定四块：**标题备选（按平台）→ 发布文案（按平台）→ 封面说明 → 事实核对**。

### 标题
- 每个平台 2–3 条备选，类型要有差别（反常识 / 数字 / 提问 / 情绪共鸣），最后给**一条首选 + 一句理由**。
- 长度上限：B 站 ≤40 字、抖音/视频号 ≤28 字、小红书 ≤20 字、YouTube 英文 ≤70 字符。
- 标题必须由成片的**真实内容**兑现：用字幕稿里的金句、核心数字或最反直觉的结论改写；不写“震惊”“99% 的人不知道”这类无法兑现的话；不堆片名。
- 不同平台的钩子不同：B 站吃“信息量 + 悬念 + 数字”；抖音/视频号吃“第二人称 + 冲突 + 口语”；小红书吃“情绪 + 收藏价值”。
- 开头金句改写时别换了意思；标题里出现的数字、年份、人名必须能在 `work/film.md` 的出处里查到。

### 发布文案
- **B 站**：简介 150–300 字（第一句直接给反常识结论 → 讲了什么 → 一句提问/行动引导评论）+ 8–10 个标签 + 分区建议 + 一条置顶评论建议（可附出处）。
- **抖音 / 视频号**：≤100 字，首句即钩子，不复述标题；3–5 个话题。
- **小红书**：正文分 3–5 小段，每段 1–2 句，给出收藏理由；5–8 个话题；emoji 最多 1–2 个。
- 末尾写**来源与声明**：出处（来自 film.md）、“示意 / 类比”说明、音乐与素材授权。
- 人设与口吻按选题基调：科技类冷静克制；人文情感类留白、不鸡汤。不替用户编造个人经历。

### 事实核对
文档最后的核对清单必须逐条打勾：数字/年份/人名与出处一致、类比没被写成结论、无夸大。

## 2. 封面：两张，4K，代码绘制

| | 横版 | 竖版 |
|---|---|---|
| 比例 / 尺寸 | 16:9，**3840×2160** | 3:4，**2160×2880** |
| 设计坐标（scale 2） | 1920×1080 | 1080×1440 |
| 安全区 | **核心内容（主体 + 全部文字）落在中央 4:3：x∈[240,1680]**；两侧各 240px（12.5%）只放氛围光、网格、星点、纹理，不放重要内容 | 四周留 ≥60px；文字块居中，不贴边 |

横版要有 4:3 约束的原因：信息流、推荐位、分享卡片常把 16:9 封面裁成 4:3 等比例，两侧边缘会丢；重要内容放中间才不会被切。

### 挑什么放上去
- 文字取自**字幕稿里最有代表性的金句或主题**（通常是开头金句的反转句，或最反常识的数字），**不是片名重复**。大字 ≤8 个字（竖版可拆两行，每行 ≤4 字），一眼读完。
- 三层文字：**钩子句**（小，悬念，≤14 字）· **金句主标题**（大，发光）· **片名**（最小，角色色，居中）。三级字号，不加第四种。
- 主体 = 成片里**最有代表性的那个画面/物体**（冷开场的主角、贯穿物），画大、画亮，占画面 30–50%，保留成片同款发光、辉光层、网格/纹理。
- 一个主色相 + 一个强调色，与成片一致；强调色只给金句。
- 不放：出处小字、数据小字、水印、平台图标、UI 卡片（封面缩略图尺寸下看不清）。

### 工程做法
```bash
# film/cover.html 由 new_film.mjs 复制（与成片共用 motion.js / kit.js / 字体 / core.js）
# 改 COPY（文案）、配色、drawSubject（把成片主体搬过来；用 core.js 就加 <script src="core.js"> 后 Core(K)）
python <skill>/scripts/fonts.py film/                                            # 封面用到新字后重跑字体子集化
node   <skill>/scripts/cover.mjs film/cover.html --out out --name <名称> --guides  # 4K 两张 + 安全区检查图
```
- `cover.mjs` 输出：`<名称>_封面_横版4K.png`、`<名称>_封面_竖版4K.png`；加 `--guides` 额外把安全区检查图（红色 = 横版两侧边缘区 / 竖版边距）写到 `work/封面检查/`，属于过程文件，不放进 `out/` 成果。
- 模板内置 `guard()`：文字或主体越出安全区时，页面会 `console.error('封面越界…')`，`cover.mjs` 会把它当页面报错打印出来——必须处理。
- 封面页同样是静态纯函数，不用随机数/时间；换字重跑 `fonts.py`。

### 封面自检（必须亲眼看）
1. 打开 `work/封面检查/` 里的安全区检查图：横版红色两侧区域无重要内容、文字没压到红线；竖版文字与主体不贴边。
2. 缩到 360px 宽再看一眼（信息流缩略图尺寸）：大字还能读出来吗？主体还认得出吗？
3. 层次：钩子句 / 金句 / 片名三层清楚，不拥挤；金句最亮最大。
4. 与成片风格一致（同字体、同色、同发光语言），不是另一套设计。
5. 常见扣分：大字叠在主体最亮的核上读不清；钩子句与金句挤在一起；片名比钩子句还抢眼；横版文字横跨超出 4:3；竖版文字块贴底。
