# 主体与视觉想法：每一句话画什么

知识讲解动画最难的不是动效，而是**给每一句话找到一个能画出来、而且好看的东西**。这份文档帮你找。

## 1. 先定三样东西

1. **主色相**：从选题里推（心理 → 金与冷银；光与神经科学 → 冷蓝与绿；概率 → 琥珀；时间 → 青）。全片关键词、高亮、发光都用它；可以有一个对立色，只用于“反面 / 警示 / 另一方”。
2. **主体语言**：全片用同一种画法——发光线描（白芯 + 两层光晕）是本风格的主语言，配合粒子与体积光。别的语言也可以（点阵、线框、纸艺），但一支片只用一种。
3. **贯穿物**：开头出现、中间回来、结尾以新状态再出现的那个画面（一座舞台、一只眼睛、一个表盘、一颗水滴）。它让 2 分多钟的片子有一根线。

## 2. 把一句话变成画面

| 句子类型 | 画面做法 | 例子 |
|---|---|---|
| 一个人 / 一个场景 | 发光线描人形 + 场景几何 + 体积光 | “深夜，他还在刷手机” → 一个发光人形坐在黑暗里，手机屏幕的光打在脸上 |
| 一个研究 / 实验 | 实验装置的线描图解 + 年份/作者出处小字 + 关键变量的读数 | “请一百个人给同一张照片打分” → 一排面孔轮廓 + 1–10 刻度尺 + 指针 |
| 一个数字 | 数字本身就是主角：巨大发光数字、粒子聚成数字、读数滚动、对比条 | “14% → 96%” 两个大数字砸下 |
| 一个对比 | 左右或上下对称构图，同一个东西两种状态，用主色和对立色 | “有计划”vs“没计划”两条走向相反的曲线 |
| 一个过程 / 机制 | 分步骤的线描图解，箭头、流动的粒子、依次点亮的节点 | 信号 → 通道打开 → 离子流入 → 神经元放电 |
| 一个尺度（极大 / 极小） | 镜头推进穿越，或圆形“放大镜”显示微观细节 | 一只手 → 手臂 → 一根神经 |
| 一个生活场景 | 真实感 UI 卡片（订单页、成绩单、聊天框、账单、日历），带细节（时间、编号、状态色） | 外卖订单：预计 30 分钟 / 已超时 12 分钟 |
| 一个抽象概念 | 给它一个名字，变成一个“装置”（“拖延计时器”）；或巨字虚影压在背景 | 背景巨字“明天”，前景人形在奔跑 |
| 一个转折 / 结论 | 画面突然简化：黑场中一句大字或一个物体，聚光灯 | “是大脑在给下一次打草稿。” |

## 3. 让画面“丰富”的具体做法

- 主体之外，永远再加：一条**标注引线**、一个**读数**、一行**英文小字**或**出处**。
- 背景层放一个和主题相关的**纹理**：神经网络、星空、DNA 字母矩阵、跑道线、网格、巨字虚影——压到 5–15% 亮度。
- 每个场景至少一个**光源**：聚光灯、光束、发光点、主体自身的光晕。
- **数字要动**：滚动、砸下、对比、和图形同步变化。
- 前景偶尔有**光斑、微尘**飘过。

## 4. 换场与转场

- 同一个例子内：镜头推近 / 拉远，元素增减，状态改变——不切。
- 换例子：粒子散开再聚成下一个主体；一道光扫过换场；镜头穿进一个物体（眼睛、门、屏幕）；闪白；全屏色彩变化。
- 片名卡前后、章节之间：全片最大的事件（闪白 + 冲击音效 + 光斑）。
- 不要用：普通的交叉淡化（除非是安静的情绪段落）、无理由的 3D 翻转。

## 5. 防八股

每支片都回答：
1. 这个选题里**最想让人截图的一帧**是什么？（通常是片名卡，或一个“哇”时刻）
2. 有没有一个**只属于这个选题**的画面（不能换个主题照搬）？
3. 和上一支片相比，主色、贯穿物、主体是否都换了？

## 6. 冷开场的情绪锚点

三轮测试里“开头”一项最难拿高分：用一个物件 + 一个放大镜开场，总是不如一个人的大特写（比如瞳孔）。冷开场要的是**一个人**，并且画面大、近、安静：
- **极近的特写**：一只眼睛占满画面（`K.iris` 放大到 R≈H），瞳孔缓慢收缩或映出一个光点；一只手、一道划痕、一枚硬币占满画面。
- **人物侧影**：`K.profile` 侧脸剪影 + 亮边 + 背后一束光，字幕说“他……”；或 `K.figure` 站在聚光灯下。
- **先暗后亮**：第 0 帧就有画面，但大部分是黑的；第一句字幕出现时，光才照到那个人或物上。
- **一个具体的细节**：日期（“1796 年 5 月 14 日”）、年龄（“一个 8 岁男孩”）、动作（“被故意种上了天花”）。
- 不要在冷开场放数据图表和多个信息层：冷开场只有一个主体、一句字幕、一束光。信息从片名卡之后再铺开。

## 7. 抽象题材的“具体物”隐喻库（数学、概率、经济、信息、时间）

抽象题材最容易落回“圆环 + 大数字”的仪表盘。每章换一个**具体的、有材质的物**来承载概念，并让全片一个物贯穿。起点（按概念找物，再按选题改造）：

| 概念 | 可以画成的物 | 奇观怎么出 |
|---|---|---|
| 人 / 个体 / 样本 | 一朵火焰（`K.flame`）、一颗光点、一个人形、一粒种子、一只萤火虫 | 一个变成满屏几千个（粒子群、烛海、星空） |
| 概率 / 机会 | 硬币、骰子、抽签纸条、彩票球、老虎机滚轮、一扇扇门 | 几百枚硬币同时抛起、门一扇扇打开 |
| 配对 / 关系 / 网络 | 线、弦、红线、电话线、神经元（`K.branches`） | 几百条弦织成曼陀罗、全屏网络同时点亮 |
| 乘法 / 衰减 / 复利 | 一层层变薄的纸、一级级台阶、一张张缩小的卡片、折纸 | 层层叠出高度 / 坍缩成一点 |
| 比例 / 份额 | 一块蛋糕、一杯水、一张饼图做成的实物（披萨、橙子切面） | 切开的瞬间、液面上涨 |
| 时间 / 周期 | 蜡烛（会烧短）、沙漏、年轮、日历、钟、季节的树 | 一年 365 格同时点燃、树一季季变色 |
| 信息 / 信号 | 光脉冲、声波、电报纸带、二维码、DNA 字母矩阵 | 满屏字符雨里亮出一个词 |
| 金钱 / 价值 | 硬币堆、钞票捆、工资条、价格标签、天平 | 硬币瀑布、天平猛地倾斜 |
| 增长 / 曲线 | 一排由矮到高的蜡烛 / 楼 / 植物（曲线用实物排出来） | 实物排成的曲线带镜面倒影 |
| 选择 / 分叉 | 岔路、树枝、地铁线路图、迷宫 | 分叉一路长满屏 |
| 熵 / 无序 | 摔碎的杯子、散开的墨、沙子、拼图 | 倒放失败的瞬间 |

规则：
- **同一个几何母题（圆环、柱状、网格）全片最多用 2 次**，第三次必须换物。
- **主角天生是球**（原子、恒星、行星、细胞、眼睛）时，换掉“正面整圆”的呈现：切开的半球截面、只露一段弧的极近特写、侧光下的明暗交界线、粒子轨迹或拖尾、从球里喷出的东西（日珥、喷流、爆炸壳）、把球放进一个具体场景（掌心里、试管里、天平上）。整圆正面构图全片最多 2–3 次。
- 每章写下“这一章的物是什么、它的奇观是什么”，再写其他句子。
- 字幕里的比喻（“比抛硬币还高”）要有对应画面：提到硬币就出现硬币。
