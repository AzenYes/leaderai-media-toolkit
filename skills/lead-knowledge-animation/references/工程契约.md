# 工程契约：让每一帧都可以准确重建

## 1. 契约（不可协商）

**任意时刻的画面都是 `render(t)` 的纯函数。** 只有这样才能抽帧检查、局部修复、多进程渲染、加运动模糊，并且保证你检查过的帧就是成片里的帧。

- 禁止用 CSS `transition`/`animation`、`setTimeout`/`setInterval`、`requestAnimationFrame` 驱动画面（预览器的播放按钮只负责推进 t）。
- 禁止 `Math.random()` 和 `Date.now()`。随机数一律用 `M.rng(seed)`、`M.hash(i)`、`M.noise*`。粒子的固定属性在加载时用种子生成一次，存进表里。
- 禁止在帧与帧之间保留状态。需要“历史”的东西（模拟、跟随、轨迹），二选一：
  - 写成 t 的闭式函数（解析式弹簧 `M.springTrack`、关键帧 `M.kf`）；
  - 在加载时用固定步长（如 1/240s）**预烘焙**整段模拟，render(t) 只做查表和插值。
- 外部资源（图片、视频、字体）在 `M.film` 之前通过 `M.image()` / `M.wait()` 注册，引擎会在第一帧之前等它们加载完。视频素材要 seek 到 t 并等待 `seeked`，render 可以返回 Promise。
- 用 `verify.mjs` 检验：同一个 t 冷跳、热跳得到的画面必须逐像素一致，页面不能有任何报错。

## 2. 工程结构

```
<项目>/
  film/
    index.html      影片本体：样式 + DOM/SVG/Canvas + render(t) + M.film({...})
    motion.js       运行时（缓动、关键帧、弹簧、噪声、预览器）——一般不改
    fonts/          本片用到的字体
    assets/         用户素材（logo、截图、照片、视频）
  work/             film.md、beats.json、cues.json、sfx/、mix.wav、中间文件
  out/              stills/、草稿、成片
```

新建：`node <skill>/scripts/new_film.mjs <项目目录>`。它会复制 `motion.js`、一份**布线示例** `index.html` 和字体。示例只演示 API 的接法，**风格和构图必须按本片方向全部重写**。

## 3. motion.js 速查

```js
M.film({ width, height, fps, duration, stage, render, scenes:[{id,start,end,label}], beats:{bpm,offset}, cues:[...] })
M.prog(t,a,b,ease)            // t∈[a,b] → 0..1
M.map(t,t0,t1,v0,v1,ease)     // 区间映射
M.kf(t,[[t,v,ease],...])      // 关键帧（数字或数组）
M.kfZoom(t,[[t,z,ease],...])  // 缩放走对数插值
M.spring(t,start,from,to,k,d) / M.springUnit(t,k,d) / M.springTrack(t,[[t,v],...],k,d)
M.springPresets               // snappy/ui/heavy/type/playful 的 [k,d]

M.canvas(parent,w,h,dpr)      // 设计尺寸的 canvas（默认 CPU 光栅，抗锯齿结果稳定）
M.frameT                      // 当前帧的中心时刻：不该参与运动模糊的层用它代替 t
// —— kit.js（丰富度工具包，见 丰富度与设计秩序.md）——
const K = Kit({ W, H, stage, duration, palette:{bg,ink,sub,accent,accent2}, font:'Plex', seed, vignette:.55, grain:.22 })
render(t){ K.begin(t); ...; K.end(t); }      // begin：清画布+画环境；end：光斑/闪白/HUD/字幕/颗粒
K.ctx / K.bg / K.bg2 / K.fg / K.world        // 主体画布 / 背景 / 星点网格 / 前景 / DOM 主体层

K.text(parent,'文字|换行[高亮]{加粗}<小字>[词#hex]',{x,y,size,w,align:'l'|'c'|'r',width,ls,lh}).reveal(t,t0,{mode:'rise'|'center'|'type'|'ink',dur,stagger}).hide(t,t1)   // align:'c' 时 x 为左边界、width 为容器宽（默认 W）

K.glowTitle(el,{color,strength}); K.slam(el,t,t0)

K.figure(c,x,y,scale,'stand'|'run'|'win'|'sit'|'fall',phase,{color,a,core})   // 可选，非默认主体，见主体与视觉想法第 2 节
K.spotlight(c,x,y,angle,width,len,a,col)
K.sample('文字'或(ctx,w,h)=>{画形状},{w,h,step,font}) → pts;  K.particles(c,pts,cx,cy,p,{spread,size,color,t})
K.ghost(c,'如果',x,y,size,alpha,weight,family); K.flash(t0,peak=.25,dur); K.shake(t0,amp,dur); K.flare(t0,x,y,peak,dur)
K.core(c,x,y,r,a,col)                         // 亮核：每帧主体最重要的位置放一个
K.orb(c,x,y,r,{color,nucleus:{r,dx,dy},membrane,atmo,spec,rim,rx,ry,rot,t})   // 材质球/细胞/星体；atmo 大气辉光，membrane 连续膜线

K.iris(c,x,y,r,{color,pupil,open})              // 眼睛特写
K.irisWipe(c,x,y,p,drawInside,open); K.lightSweep(c,p,drawNew,{color}); K.pushThrough(t,t0,dur)   // 转场原语（遮罩内会先铺底色）
K.flame(c,x,y,h,{t,seed,color,glow,lean,shimmer}); K.fog(t,color,a); K.rays(c,x,y,t,a,color,{n,len})   // 火焰、章节色雾、放射光丝

K.profile(c,x,y,h,{color,facing,rim})          // 人物侧脸剪影：冷开场的情绪锚点
K.caption.set(lines,{colors:{抗体:'#ffc14d',病毒:'#ff6a5c'},shade:.55,size:52,hookSize:104,hookY:H*.64})  // 字幕单行自动适配（字体按 lines.json 的 font）；hook 句大字；关键词角色色；底部暗化
K.text 里 [词#ffc14d] 可单独指定高亮色
K.camKeys([[t,zoom,worldX,worldY,ease],...]); K.camAt(t); K.toScreen(t,wx,wy); K.safe(t,wx,wy,ww,wh,tag)   // 景别变化与安全框
K.lens(c,srcX,srcY,x,y,r,p,(c,rr,k)=>{...镜内以镜心为原点...},{label,sub,color})   // 圆形放大镜
K.card(c,x,y,w,h,{title,sub,accent,p}) → 内容区; K.roundRect; K.grow(c,pts,p,{w,color}); K.scribble(c,x,y,rx,ry,p); K.mix(c1,c2,p)→hex
Kit({..., bloom:.9})                            // 辉光层：只让亮部发光（0 关闭）
// 地图与地球（geo.js + world110.js，Natural Earth 110m 公有领域）：
const G = Geo(K); G.globe(c,{lon0,lat0,R,cx,cy},{day,sun,tint}); G.route(wps); G.globePath(c,g,r,p,{lift}); G.map(c,{lon0,lat0,scale,cx,cy}); G.mapXY; G.proj; G.hav; G.comet; G.burst
M.step(t, fps)                // 按 fps 步进的时间（12fps 手作感 / 定格）
M.image(src) / M.wait(promise)
```

技术选择：
- **DOM + CSS transform**：文字、UI、版式类。排版质量最好，中文字体渲染也最好。
- **SVG**：线条生长（`pathLength=1` 加 `stroke-dashoffset`）、形变、遮罩、图标。
- **Canvas 2D**：粒子、生成艺术、大量对象、像素风。
- **WebGL / Three.js**：shader、3D、大量粒子。three.js 需要放到本地（`film/assets/three.min.js`），渲染环境可能没有网络。
- 混合使用没有问题，所有层都放进 `stage`，由同一个 render(t) 驱动。

## 4. 渲染命令

```bash
S=<skill>/scripts
python $S/fonts.py film/                                # 屏上文字改动后：字体子集化（否则中文字体会静默失败）
node $S/verify.mjs film/index.html                      # 纯函数 + 报错 + 字体检查（每次大改后跑；--tol 容差默认 2）
node $S/stills.mjs film/index.html --scenes             # 每个场景中点一张 + 联系表
node $S/stills.mjs film/index.html --every 0.5          # 全片节奏
node $S/stills.mjs film/index.html --boundaries         # 场景边界 ±3 帧条带（查闪帧、接缝）
node $S/stills.mjs film/index.html --range 4.6:5.4:0.0167   # 快动作逐帧
node $S/stills.mjs film/index.html --every 1 --phone    # 按手机宽度渲染，查可读性
node $S/stills.mjs film/index.html --at 5 --crop 0,800,1080,400 --scale 2   # 放大看局部（小字、接缝）
node $S/stills.mjs film/index.html --every 1 --query "ratio=9x16"           # 同一工程出别的画幅
node $S/compare.mjs a.png b.png c.png --labels "A,B,C" --out out/cmp.png     # 方向对比、改前改后
node $S/render.mjs film/index.html --out out/draft.mp4 --fps 30 --scale 0.5           # 草稿
node $S/render.mjs film/index.html --out out/fix.mp4 --from 8 --to 11 --scale 0.5     # 只渲受影响的区间
node $S/render.mjs film/index.html --out out/final.mp4 --fps 60 --blur 8 --audio work/mix.wav   # 成片
```

- 草稿用 30fps、0.5 倍、不加运动模糊；成片用 60fps（或 30fps）、1 倍或 2 倍、`--blur 8`。
- 耗时 ≈ 时长 × fps × 子帧数 ÷ 截图速度 + 约 2 分钟编码。实测 1080p 约 25–45 张/秒（取决于画面复杂度与 CPU 核数）。审片阶段只用 30fps 半分辨率草稿，成片只在最后渲一次；只改一段时用 `--from/--to`。
- 编码：H.264、yuv420p、BT.709、CRF 16、faststart。上传平台用这个参数就够了。

## 5. 常见坑

| 症状 | 原因 / 解法 |
|---|---|
| Windows + Git Bash：带中文路径的 python -c / 嵌套引号 heredoc 解析失败 | 把脚本写成文件再运行（python 文件路径.py） |
| 预渲缓存导致 verify 误报 | 精灵、火焰帧、纹理这类缓存要在加载时一次性生成，不要等第一次用到才生成 |
| 第一帧字体不对 | `@font-face` 只有被用到才会加载；首帧就要用上，或者显式调用 `document.fonts.load('700 100px Plex')` 并通过 `M.wait` 注册 |
| verify 不通过 | 有 Math.random、Date.now、累积状态，或者 CSS transition 还开着 |
| 缩放后文字发糊 | 去掉 `will-change`；静止时去掉 filter 和亚像素 transform；大字用 DOM 而不是放大的 canvas |
| 换字时新旧重叠 | 形变容器里的文字要有独立的进出时间：形变开始后约 0.08s 再进，下一次形变开始前约 0.1s 先退 |
| 层级错乱、闪一帧 | 每一层都显式设置 z-index；场景边界用 `--boundaries` 检查 |
| 循环接缝卡顿 | 末帧必须与首帧完全一致（位置、速度、光标都要一致）；只渲染 0..N-1 帧 |
| 色块泛滥像闪光 | 覆盖时间 ≥0.3s，并且要盖过最远的角 |
| 4 子帧有残影 | 用 8 子帧，或者放慢动作 |
| 全帧 blur 很慢 | 在小画布上模糊，或者预烘焙；静止的文字烘成位图 |
| `file://` 加载失败 | 渲染脚本已经开启 file 访问；视频素材建议转成全 I 帧（`-g 1`）以保证 seek 准确 |
| 页面打不开、一直等待 | 渲染脚本会把页面报错打印出来；常见原因是变量名和 window 属性冲突（如 `const top`、`name`、`status`），换个名字 |
| CSS 3D 共面层闪烁 | 共面的层排序不稳定：给每层一个微小的 translateZ 差（0.1px 级），或者改成按深度手动排序的 2D 绘制；verify 的“连拍不同”往往就是这个 |
| CSS 3D 外层盖住内层 | 错峰的顺序和 z 顺序要一致；需要透视叠层时，优先在 canvas 里按画家算法从远到近画 |
| 运动模糊让数字重影 | 那一层用 `M.frameT` 或 `M.step` |
| 渲染文件和预览不一致 | 检查是否有依赖窗口尺寸的代码；所有布局都按设计尺寸写，不读 innerWidth |
