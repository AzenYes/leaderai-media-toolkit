# 风格范式：发光线描式知识讲解动画

本 skill 的目标风格：2–3 分钟的知识讲解动画，**没有配音**，靠底部字幕 + 画面 + 音乐音效讲故事。以下是风格的结构、视觉语法和节奏，所有判断都以它为准。

## 1. 它为什么抓人

- **选题**：一个日常现象背后的反直觉原理（说得越多信息量越少、第二名比第三名难过、两个一样的地方之间不会起风），或者一个热点科学成果讲成一个人的故事。
- **冷开场**：第一帧就是一个具体的画面加一句悬念字幕，没有片头、没有自我介绍。
- **开头金句**：前 5 秒内用大字出完 1–2 句金句。
- **片名卡**：5–9 秒出现，巨大的发光宋体标题 + 英文小字副标题 + 一句问题。
- **证据感**：年份、研究者、实验设计、具体数字，配出处小字，让观众觉得“这是真的”。
- **生活例子**：订单页、成绩单、手机聊天框这类观众熟悉的界面，用真实感 UI 卡片做出来。
- **回环**：结尾回到开头的画面，用新的理解重看一遍，再出片名。

## 2. 视觉语法

| 元素 | 做法 |
|---|---|
| 底色 | 近黑（#05060a 一类），带极淡的氛围光（某一侧有冷色或暖色光雾） |
| 主色调 | 每支片一个主色相（金 + 冷银、冷蓝 + 绿、琥珀……），关键词、高亮、发光都用它；每章可以换色温 |
| 主体 | **发光线描 + 有材质的插画式物体**：物件、器官、细胞、神经元、动物、地形、界面、人的局部（眼睛、手、侧影）——白芯 + 两层光晕，线条有粗细。主体按每句文案选最能说明它的那个东西，**没有默认主体**；人形只是可选项之一，不是本风格的标志 |
| 粒子 | 粒子聚成数字、阶梯、人群、大脑、星系；粒子散开 = 转场 |
| 光 | 舞台聚光灯（体积光锥 + 光里的浮尘）、从一点射入黑暗的光束、镜头光斑 |
| 背景 | 巨字虚影（极大极淡的关键字）、神经网络/星空/网格等纹理，压得很暗 |
| 信息 | 真实感 UI 卡片（订单页、成绩、DNA 序列、实验记录）、刻度尺、计时读数（0.010 s）、引线标注、圆形“放大镜”看微观 |
| 字幕 | 底部单行 52px，句末不带标点；字体按内容选（理性科技用 IBM Plex Sans SC Medium，人文故事用思源宋体 SemiBold），白色，关键词加粗 + 强调色；逐字带模糊显现，读完即换 |
| 角标 | 左上极小的章节英文名（可选） |
| 片名 | 宋体粗体 120–180px，白芯 + 冷色多层光晕，下方英文小字和一句问题；片名下常有同心圆/光环 |

## 3. 节奏

- 字幕约 2.5–3.5 秒一句（逐字显现约 16 字/秒，然后停留到读完）。
- 画面每句都变：新元素进入、主体动作、镜头推近、数字跳动；同一个例子内连续，换例子换场景。
- 每 20–30 秒一次大转场（粒子散开重聚、闪白、镜头穿越、全屏色彩变化）。
- 音乐全程在（持续的、节奏感明确的配乐），音效点在大事件上（数字砸下、灯亮、门开、转场）。

## 4. 两种开头

- **纪实叙事**（心理、社会、人物、诺奖）：冷开场一个人或场景 → 片名卡 → 研究 → 生活例子 → 机制 → 升华 → 回环。
- **结论先行**（物理、宇宙、科技、概率）：一个反常识结论 + 数字 → 片名卡 → 逐层解释 → 回到结论。可以加 HUD 框架（章节号、读数、时间码）和星云环境，见 `丰富度与设计秩序.md` 第 5 节“科幻 HUD”。

## 5. 怎么用

- 每支片都要找到属于这个选题的主体：什么东西可以画成发光线描？什么可以变成粒子？哪个生活界面可以做成 UI 卡片？
- 审片时对照 `丰富度与设计秩序.md` 的指标和 `qa_video.py` 的亮度指纹，检查：每句画面是否都在变、每帧有几层、主色是否克制、字幕节奏是否一致。想要并排对比时，用 `compare.mjs` 比较本片的不同方向、改前改后，或自己此前做过的达标成片。
