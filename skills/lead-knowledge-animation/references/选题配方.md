# 选题配方：不同知识类型哪里最容易做坏

每类只写和通用流程不同的地方，是起点而不是模板。

## 心理学 / 社会现象（比如“为什么第二名更难过”这类对比心理）
- 纪实叙事开头：一个具体的人在一个具体的时刻（赛场、考场、深夜的手机屏幕）。
- 证据：一个经典研究（年份、作者、方法、数字），画成实验图解，不要只放一张论文截图。
- 机制给一个好记的名字（“现时偏好”“享乐跑步机”），变成一个可视化装置，后面反复出现。
- 生活例子是灵魂：选观众一定经历过的（外卖、成绩、工资、恋爱、排队），用 UI 卡片做出真实感。
- 主体：发光线描人形（站、跑、坐、举臂），用颜色区分“现实的你 / 平行宇宙的你”。

## 诺奖 / 科研成果（比如光控神经元这类成果）
- 冷开场是受益的人（“她失明多年，直到那一天”），而不是科学家或奖项。
- 讲成一个探案故事：最初的谜题 → 意外的线索（一种藻类、一段基因）→ 关键实验 → 改变了什么。
- 微观结构（细胞、通道、分子）用发光线描 + 圆形放大镜；时间线标年份。
- 结尾回到那个人。

## 物理 / 宇宙
- 结论先行：一个反常识结论 + 数字（“你头顶的时间比脚下走得更快 · +38μs/天”）。
- 视觉可以混入科幻 HUD 框架：章节号、读数、星云、视差星空、精细仪表。
- 尺度陷阱：跨数量级时让镜头“追不上”主体，或切回线性尺度并排熟悉参照物。
- 时空、场、波这类抽象物用网格变形、粒子流、等势线来画。

## 数学 / 概率 / 信息论（比如“重复多少遍信息量归零”这类选题）
- 片名直接放公式或数字（“0.8⁵ = 33%”）也很抓人。
- 每一步推导都要有画面对应：概率 = 一格格点亮的方块、乘法 = 方块一层层减少、信息量 = 信号条变短。
- 生活例子把公式落地（每个“也许”都要付钱）。
- 数字全部要算对，画面上的格子数要和数字一致。

## 生物 / 医学
- 器官、细胞、分子用发光线描 + 半透明填充；配真实比例尺和单位。
- 过程用流动的粒子表现（血流、离子、信号）。
- 避免血腥写实；示意结构标“示意”。

## 经济 / 商业
- 一个人的账本做贯穿物（工资条、购物车、K 线）。
- 数据图表：先坐标系，再数据，只标一件事；金额用等宽数字滚动。
- 结论要克制，不要变成鸡汤或投资建议。

## 历史 / 人物
- 冷开场一个具体时刻（某年某月，一个人在做一件事）。
- 地图、年表、档案纸张、印章是好的视觉素材；年份做成大号读数。
- 引用原话必须有出处，没有就转述。

## 书籍 / 观点
- 不按章节罗列，选书里 2–3 个最反直觉的观点，各配一个生活例子。
- 开头用书里最惊人的那个结论，而不是“这本书讲了什么”。
