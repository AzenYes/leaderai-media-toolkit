# 运动语言：把形容词翻译成数字

> “形容词是默认外观住的地方。每把一个形容词换成数字，就从模型手里收回一个决定。”

下面所有数字都是**起点**，不是标准。要按具体镜头试出来，并且写进本片的 `film.md`，成为本片自己的 token。

## 1. 层级：一次只看一个地方

- **每个镜头只有一个主动作（hero move）**。其他元素等待、压暗到约 40%，或保持静止。
- **次级动作**：位移是主动作的 50–70%，晚 100–200ms 开始。
- **环境动作**：幅度不超过主动作的 5%，用慢正弦或噪声，永远不停。它的作用是保证画面“活着”，不和主角抢注意力。
- **错峰（stagger）**：前一个元素完成 30–50% 时下一个开始。参考值：字母 1 帧 / 词 60–120ms / 列表项 40–80ms。错峰本身也可以套缓动，比如先密后疏。
- **主次比例**：主词和辅句的字号至少 3:1；背景元素的饱和度、对比度、线宽都比主角低一档。

## 2. 缓动：小而统一的词汇

全片只用 4–6 条曲线，写成 token：

| 用途 | 曲线 | cubic-bezier |
|---|---|---|
| 文字 / logo 揭示 | expo-out | 0.16, 1, 0.3, 1 |
| 高级感入场 | quint-out | 0.22, 1, 0.36, 1 |
| 移动、推镜 | quart-inOut | 0.76, 0, 0.24, 1 |
| 快速退场 | expo-in | 0.7, 0, 0.84, 0 |
| 俏皮回弹（慎用） | back-out | 0.34, 1.56, 0.64, 1 |

规则：
- 入场用 ease-out，退场用 ease-in，**退场时长比入场短 40–50%**。
- **linear 只用于**旋转、进度条、循环相位、恒速漂移。“移动用 linear，是让渲染一眼看起来像渲染的最快方法。”
- 引擎写法：`M.ease.bezier(.16,1,.3,1)`，或者直接用 `M.ease.outExpo` 这类命名曲线。

## 3. 弹簧：落地时有一点点回弹

用阻尼比描述弹簧的性格（`M.springUnit(t, k, d)`，阻尼比 = d / (2√k)）：

| 阻尼比 | 观感 | 用在哪 |
|---|---|---|
| 1.0 | 不弹，稳 | 相机、大标题、沉重物体 |
| 0.7–0.85 | 高级、利落 | UI、卡片、容器形变 |
| 0.4–0.6 | 俏皮 | 吉祥物、贴纸、图标 |
| < 0.3 | 卡通 | 几乎不用 |

- **位置和尺寸可以弹，透明度和颜色绝不弹。**
- **文字不加回弹。** UI 可以有一点点过冲，大字、logo 定版不要。
- **前后沿分别挂不同的弹簧**：比如指示条的前沿用 320/30，后沿用 140/22，移动时会自然拉长再收回。这是“高级 UI 动效”最便宜的来源。
- **换目标时叠加弹簧，不要重启**：`M.springTrack(t, [[t0,v0],[t1,v1],...])`。这样中途打断也不会跳变。
- 拖拽这类直接操控要跟手，松手后从当前位置弹回。

## 4. 时长与停留

- UI 反馈 100–200ms；UI 移动 200–500ms；主角揭示 600–900ms；场景交接 300–600ms。
- **阅读时间**：文字静止至少满足“每词 0.3s + 0.5s”；中文按每秒 4–5 字估算。**被阅读的文字不能在动**（可以有极慢的整体漂移，但不能有位移动画）。
- **句级大事件（2.5–5s）+ 秒级小事件（~1s）+ 持续的环境运动**。讲解片里画面是在“陪着字幕讲”，所以变化要比纯视觉片更频繁；停住阅读时，主体之外仍有标注生长、读数跳动、环境层在动。
- 开头 0–2 秒：**第 0 帧就在动**，而且要是一个具体的画面，不是标题。
- 结尾：落在主物的一个动作上，然后停留 0.8–1.5s 让观众记住。
- 一个镜头 2–6 秒；加速感来自**每段变短**（6→4→3→2→1 拍），不是把动作调快。
- 手机端的关键姿态要夸张 10–30%，因为小屏会吃掉细微的动作。

## 5. 相机：镜头是标点

每次动相机之前先回答三个问题：观众这一刻该看哪？这一下是过渡还是重音？上一个镜头做了什么动作？

| 动作 | 参考参数 | 用法 |
|---|---|---|
| 缓推 | 0.6–1.5s，sine/quart-inOut，推近 10–40% | 引导注意力、进入细节 |
| 拉远 | 0.8–2s，长尾 | 揭示全局、收尾 |
| 横移 | 0.5–0.9s | 并列信息、时间推进 |
| 快推 | 0.25–0.35s，推近 18–32% | 重音 |
| 甩镜 | 0.26–0.30s，带方向运动模糊 | 强转场 |
| 砸入 | 0.17s，1.55→0.94→1.0 | 极强重音，落在重拍 |
| 慢漂 | 每秒 1–4% | 只给氛围镜头 |
| 冲击 | 1.03→1.0，约 0.3s | 落地、揭示的瞬间；新旧两层要一起冲 |

规则：
- **一个视觉节拍只做一次主相机运动**（环境层的慢漂/呼吸一直存在），不要推完马上拉。不要连续三个节拍都往里推。
- 重音类动作（快推、砸入、甩镜）**不超过镜头数的 1/3**。
- 缩放在**对数空间**插值（`M.kfZoom`），否则推近会“前快后慢”。
- 反面标尺：102 秒推近 48 次，作者评价“一点都不 smooth”；每个镜头匀速推近 7.5%，作者评价“完全是放 PPT 的感觉”。病根相同：**每个镜头都用同一个动作**。
- 相机跟随移动的主角时，用临界阻尼弹簧加一点速度前瞻，不要硬锁。
- 想让观众看出相机在动，背景里需要参照物，比如点阵、网格或纹理。

## 6. 转场：转场是物体，不是剪切

按优先级排列：
1. **形变接续**：上一镜的物体直接变成下一镜的物体，比如按钮长成页面、圆点长成背景、字变成线。
2. **共享元素**：同一个元素移动并缩放到新位置，而不是消失后再出现一个复制品。
3. **色块泛滥（flood）**：颜色从一个物体里涌出覆盖全屏，约 0.3–0.35s，**必须盖过最远的角**，否则看起来像闪了一下。之后再缩回另一个物体。
4. **遮罩揭示**：文字从遮罩线下升起，下一组从另一侧推进；两组词**在任何像素列上都不能同时出现**。
5. **相机穿越**：推进一个物体的内部（字母的洞、屏幕、眼睛），到达下一个世界。
6. **硬切**：落在重拍上，作为一个有意的决定。它比糊掉的交叉淡化更高级。

避免：所有场景都交叉淡化、模糊淡入、无理由的 3D 翻转、方向来回反复的相机。

**风格转场**：场景切换到另一种风格时，下一种风格的“签名语言”从画面里某个物体中**从无到满地长出来**，比直接切换高级得多。

## 7. 镜内运动：反静态幻灯片

“图片之间做转场”不算动效。每一幕都要有：
- **一个主动作**（这一幕要讲的变化）；
- **2–4 个取自本片母题的小循环**（风格自带的元素：水纹、星点、纸片轻颤、光的呼吸、数据流动）；
- 两层帧率：相机和主动作保持平滑，手作类元素用 12fps 一拍二，这样有温度又不卡。

自检：在任意一秒暂停，问“这一秒里什么在动，为什么动”。答不上来就是死画面；答案是“所有东西都在动”就是太躁。

## 8. 文字动效（中文尤其注意）

- **遮罩上推**是最可靠的高级入场：文字放在 `overflow:hidden` 的行框里，从下方升起，expo-out，0.6–0.8s。逐字错峰 20–40ms。
- 中文**逐字动画**时，每个字单独成层容易破坏字距和标点挤压。更稳的做法是整行渲染，用遮罩按字的位置裁出来。
- 标题的字距：中文大字用 -0.01 到 -0.03em 收紧，小字用 0.02–0.08em 放开。数字用 tabular 或等宽体，滚动时才不会抖。
- 数字滚动：`Math.round(M.map(t, a, b, 0, 1234, E.outExpo))`，落定后停 ≥0.5s。
- 字号底线（1080p 设计坐标）：要观众读的辅句 ≥48px，标注和来源 ≥34px（只给愿意暂停的人看），英雄字 ≥120px。竖版再放大约 1.3 倍。用 `stills --phone` 检查：读不出的字要么放大，要么删掉。
- 不要用：打字机效果做标题、文字渐变、文字发光、每行都 fade+slide-up。
- 汉字的视觉中心偏上，几何居中会显得偏下。重要的单字或 logo 按**墨迹**居中，不按字框居中。

## 9. 运动模糊与清晰

- 快速运动用**子帧运动模糊**：`render.mjs --blur 8 --shutter 0.5`。4 个子帧在快动作上会留下残影，用 8 个，或者把动作放慢。
- **不该被模糊的层**（快速滚动的数字、小字、HUD）读 `M.frameT`（帧中心时刻），不要读 t。这样子帧之间这一层完全一样，不会叠出重影。也可以用 `M.step(t, 12)` 让它按整帧步进。
- 静止时**移除 filter 和多余的 transform**，让文字锐利。不要在会被相机缩放的元素上加 `will-change`，文字会发糊。
- 过冲必须有上限（比如最多 24px）。到达静止时间后**强制吸附到精确的静止态**，否则会残留亚像素的模糊。

## 10. 把感受翻译成参数（修改时用）

| 用户 / 你的感受 | 通常的改法 |
|---|---|
| “不够 pop” | 缩放 1.0→1.08→1.0，6 帧，峰值落在拍上；配一个短冲击音效 |
| “不高级” | quint-out 入场，阻尼比 0.8，文字不回弹，去掉一半元素，换成形变转场 |
| “拖沓” | 每段停留减 12 帧；砍掉没有信息的镜头；加速段逐段变短 |
| “太乱、太忙” | 一次只留一个主动作，其余晚 150ms、位移 60%；“删掉 30% 的运动，只保留引导视线的” |
| “像 AI 做的” | 点名它用了哪些默认效果（渐变、发光、粒子、淡入、居中），逐个禁掉后重渲 |
| “像 PPT” | 加镜内运动，换成形变或共享元素转场，相机不要每镜同一个动作 |
| “太快看不清” | 每个信息点给 6–8 秒，保证每行字能读两遍 |
| “太平” | 加纵深层次（前景虚化、视差）、明暗两层平涂、一个尺度变化 |
