# 声音：音乐托底，音效点睛（不配音）

这类视频没有人声。声音只做两件事：**音乐让画面不空**，**音效让大事件有重量**。

## 1. 音乐

- 全片要有持续的配乐（节奏感明确、不抢戏）。取曲顺序：
  1. 用户指定了曲子 → 只用用户的（交付时注明来源），**不要再提内置曲**；
  2. 用户明确说“只要音效 / 不要音乐” → 不加音乐；
  3. 用户没提音乐 → 先跑 `python <skill>/scripts/bgm.py --check`。本机有配套曲（Claude 小曲，177.5 秒，单独分发的配套包）→ **先问用户**“要不要用 Claude 小曲做 BGM”，同意才用；用户无法回答时默认用并在交付说明里写明。本机没有 → 不提这首曲子，问用户有没有想用的曲子，或只用音效 / `sfx.py --bed` 垫底。
  配套曲的安装、drop 位置和长度限制见 `assets/music/README.md`。
- 有音乐时先测拍：`python <skill>/scripts/beats.py music.mp3 --out work/beats.json`，再 `timeline.py --beats` 让字幕切换踩拍；片名卡、大转场放在重拍或 drop 上。
- 没有可用音乐、又需要垫底时，可以用 `sfx.py --bed <秒> --mood calm|pulse` 生成一段克制的氛围底，音量压低（-20 dB 左右），只做“空气”。

## 2. 音效：只放在看得见的大事件上

| 画面事件 | 音效 | 备注 |
|---|---|---|
| 片名卡出现 | impact + riser（riser 用 align:end 收在出现那一刻） | 全片最响的一下之一 |
| 大转场（粒子散开 / 闪白 / 穿越） | whoosh 或 reverse | |
| 数字砸下、结论出现 | thump | 配一次镜头冲击 |
| 灯亮、光束射入、门开 | chime 或 swish | |
| 计时、打分、读数跳动 | tick（变体轮换） | 密集时压低 |
| UI 卡片弹出、点击 | click / pop | |
| 故障、错误、反转 | glitch | |

- **不给每句字幕配音效**（字幕逐字出现不需要打字声，除非这一段就是在“打字”）。
- 全片一个音色家族；重复的音效在变体之间轮换（`sfx.py --variants 3`）。
- 音效写进 `M.film({ cues })`，时间引用 `L.<id>.start`，不要手抄数字。

## 3. 混音

```bash
node   <skill>/scripts/cues.mjs film/index.html > work/cues.json
python <skill>/scripts/sfx.py --out work/sfx --variants 3
python <skill>/scripts/mix.py --cues work/cues.json --sfx-dir work/sfx --out work/mix.wav --duration <总秒数> \
       [--music music.mp3 --music-db -6 --music-dips 13.0-13.4:-18] --lufs -14 --tp -1.5
```

- 有音乐：音乐是主体响度，音效比音乐局部高 3–6 dB；片名卡前 0.3–0.4 秒用 `--music-dips` 让音乐收一下，冲击更有力。
- 只有音效：响度目标仍是 -14 LUFS 附近，但安静段落允许真正的安静。
- 手机外放播不出 60Hz 以下：重音要有中频成分。
- **你听不到声音**：不要说“声音很好”，列出 3–5 个需要人耳确认的时间点（最响的一下、最密的一段、开头、结尾）。
