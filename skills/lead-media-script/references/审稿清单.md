# 审稿清单与复盘

分轮检查，每轮只看一件事；改风格时不能偷偷加强结论。

## 一、交付前自检（每次必过）

**第1轮 · 事实与承诺**
- [ ] 稿中有没有编造的经历、数据、评论、测试、平台规则？→ 改为【待补】或删除
- [ ] 每个数字都有来源或用户提供？单次结果没被扩成普遍规律？
- [ ] 标题、封面字、开头、正文是同一个承诺？标题每个承诺都能在正文找到对应段落？
- [ ] 有没有"最强/第一/必火/100%"等无法证明的词？有没有夸大后果制造焦虑？
- [ ] 易变信息（版本、价格、功能、政策）标了"需发布前核实"？
- [ ] 有可靠数据时，开头是否用了"数据反常识"结论？开头数字可验算或有原始出处、假设已写明？

**第2轮 · 结构**
- [ ] 反向提纲：每段写一句话作用，有没有两段说同一件事？
- [ ] 删除测试：删掉某段主线还成立吗？成立就删
- [ ] 相邻段之间能说出"所以/但是"吗？
- [ ] 中段有新信息（例子、转折、反例），不是原地重复？
- [ ] 结尾回扣开头承诺，只有一个主要行动？

**第3轮 · 口播可念性**
- [ ] 默读模拟大声念：哪句需要换两次气？→ 拆
- [ ] "这个/那个/它/这里"都有明确指向？
- [ ] 术语第一次出现有大白话解释？
- [ ] 抽象名词串改成具体动词了吗？
- [ ] 删掉空泛套话（毋庸置疑、非常重要的是、那么接下来、众所周知）
- [ ] 字数与目标时长匹配（参考 4–4.5 字/秒，实际以本人试读为准）

**第4轮 · 平台**
- [ ] 结构、节奏、结尾互动符合目标平台的消费场景？
- [ ] 无其他平台残留用语？商业合作是否需要标注？

## 二、审核他人稿件的输出格式

不先整体重写。按下表列出，再给最小修改后的稿件：

| 问题位置 | 原因 | 修改建议 | 依据 / 待验证 |
|---|---|---|---|

不改变作者立场；不补造经历；需本人试读或实测的问题明确保留。

## 三、发布后复盘（用户带来数据时）

| 观察现象 | 优先核对 | 可测试的文案修改 | 不能直接下的结论 |
|---|---|---|---|
| 曝光少 | 题材需求、渠道、账号状态、统计窗口 | 让主题对象更明确 | 一定是开头不够刺激 |
| 有曝光但点击少 | 标题封面一致性、主题清晰度 | 测试更清楚的主题与价值 | 越夸张越好 |
| 开头流失明显 | 承诺是否兑现、是否有冗长铺垫 | 先给任务或结果示范 | 所有开头都必须同样短 |
| 中段流失 | 对应段落是否重复、跳跃、难懂 | 补必要解释，删重复论证 | 加转场就能修复 |
| 有回看峰值 | 是惊喜、细节需要，还是没听懂 | 放大关键演示或改清表达 | 峰值一定是优质段落 |
| 收藏多、关注少 | 一次性工具还是持续栏目 | 交代后续会持续解决的任务 | 收藏无效 |
| 播放高、转化低 | 对象适配、证据、成本、行动路径 | 回答真实顾虑 | 一定要加催促语 |

复盘原则：
- 每次只记录一个主要改动假设（如"先展示成品是否比先讲背景更好"）。
- 和本账号同类主题、相近长度的内容比，不拿单条爆款证明公式。
- 没有随机测试时，前后对比只是线索，选题、时间、流量来源都可能是原因。
- 复盘记录模板：作品与版本｜平台、形式、时长｜数据窗口与指标定义｜本次改动假设｜观察到的事实｜可能解释｜混杂因素｜下次只验证的一项｜暂不纳入规则的判断。
