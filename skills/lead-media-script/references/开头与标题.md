# 开头与标题：建立一个可兑现的承诺

标题负责"让人知道这说的是什么、为什么值得点"；开头负责"证明继续看值得"。标题、封面字、第一句必须是**同一个对象、同一个问题、同一种预期**。

## 一、开头机制（选 3 种不同的写候选）

**有事实数据时优先用第一行"数据反常识"。**

| 机制 | 怎么写 | 示例（教学虚构） | 边界 |
|---|---|---|---|
| ★数据反常识（优先） | 第一句给一个具体数字，直接推翻直觉；可用"提问→否定直觉→给数字"的节奏 | "亏百分之五十，要涨多少才能回本？不是百分之五十，是百分之一百。" | 数字必须可验算或有原始出处；不用来源不明的流传数据；依赖假设时写明假设 |
| 结果先看 | 先给成品/前后对比，再讲怎么做 | "这句'有效提升编辑效率'，改成'选中这两段再点合并'，观众马上能跟做。" | 不能只展示最好一次却隐去条件 |
| 具体场景 | 用观众能认出的时刻代替背景 | "稿子写完了，一开录，每句话都卡。" | 场景必须连到后文任务 |
| 具体问题 | 提一个能立刻理解、后文会回答的问题 | "为什么AI写的稿子信息很多，你却念不出口？" | 后文必须给答案，不用假问题 |
| 误解澄清 | 点出常见误解并给条件 | "口语化，不是多加几个'啊''呢'。" | 不把不存在的观点当靶子 |
| 意外但准确 | 用真实矛盾制造好奇 | "删掉一句解释，步骤反而更清楚了。" | 必须在正文展示具体删改 |
| 代价明确 | 说清这个问题影响什么 | "步骤里一个'这个'没说清，观众就会点错按钮。" | 不夸大后果、不制造恐慌 |
| 决策切口 | 把泛介绍改成二选一 | "什么时候写逐字稿，什么时候只列提纲？" | 不凭偏好制造唯一答案 |
| 约束切口 | 加入真实资源限制 | "只有一部手机，怎么录清楚操作教程？" | 约束必须真的影响方案 |
| 证据预告 | 告诉观众接下来看到什么依据 | "接下来用同一段原稿，改给你听。" | 说了"有数据"就必须给数据 |

**禁用开头**：寒暄、自我介绍、"今天给大家分享几个干货"、"99%的人都不知道"（无证据）、"看完这条你就能月入过万"（无法兑现）。

**有用的悬念 vs 欺骗性悬念**：可以保留"方法怎么奏效"的悬念；不能隐藏识别主题必需的信息，也不能"最后才揭晓"却没有真正的揭晓。

## 二、选题切口（想法太泛时用来收窄）

- **任务句**：谁，在什么场景，遇到什么阻碍，看完能做成什么。
- **失败切口**：从一个真实失败倒推原因（没有真实经历就写成假设或示例）。
- **系列拆分**：大题拆成能独立兑现的小题，本条只做一个。
- 热点只是候选信号；没有增量信息时，追热点只会变成重复摘要。

## 三、标题写法（出 3 个不同角度）

| 角度 | 示例 |
|---|---|
| 明确收益（能完成的动作） | 把一段功能介绍，改成观众能跟做的演示稿 |
| 具体问题 | 口播稿一念就卡？先查这三种句子 |
| 条件对比 | 逐字稿还是提纲？看你录的是哪种视频 |
| 意外但准确 | 删掉一句解释，教程反而更清楚 |
| 可证实数字 | 录口播前，先过这 4 项检查（必须真的是4项） |

规则：
- 主题对象放在前面、容易看到的位置。
- 数字只在确有对应数量/测量/样本时用；"最强""全网第一"需证据。
- **承诺审计**：给标题里每个承诺标出正文对应段落；缺内容就缩小标题范围，而不是硬撑。
- 不同平台的标题长度、标签数量不设固定口诀，按当前平台实际情况调整。

## 四、封面字

- 封面提关键状态/冲突（如"读不顺"），标题补完整主题，两者互补。
- 避免封面和标题都只剩情绪词。
