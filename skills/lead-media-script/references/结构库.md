# 结构库：按内容类型选结构

结构是帮助理解的工具，不能替代素材。先判断内容类型，再选结构；每段标注作用，写完做"删除测试"——删掉这段主线是否还成立。

## 一、类型 → 结构速查

| 内容类型 | 推荐结构 | 必备素材 | 常见误用 |
|---|---|---|---|
| 快速回答 | 结论 → 关键理由 → 一步行动 | 可直接回答的问题 | 用悬念拖延明确答案 |
| 操作教程 | 成品 → 前提条件 → 步骤 → 怎么判断成功 → 出错怎么办 | 真实操作与失败分支 | 只列按钮，不说成功标志 |
| 观点论证 | 判断 → 理由 → 证据/例子 → 反例 → 适用边界 | 来源与反方理由 | 把态度当证据 |
| 测评/选择 | 使用任务 → 评判标准 → 同条件比较 → 代价 → 适合谁/不适合谁 | 测试条件、版本、结果 | 只比功能数量 |
| 经验故事 | 场景 → 目标 → 阻碍 → 行动 → 结果 → 反思 | 可核验的真实经历 | 每篇都编挫折与逆袭 |
| 避坑/问题解决（PAS） | 问题 → 影响（不夸大）→ 解决方法 → 验证 | 真实问题与可行方案 | 夸大后果、制造焦虑 |
| 结果展示（4Ps） | 场景 → 承诺 → 证明 → 行动 | 前后状态与实现条件 | 只有漂亮结果，不讲成本 |
| 种草/产品介绍（AIDA） | 注意 → 兴趣（具体需求）→ 欲望（证据）→ 行动（含适用对象与限制） | 需求、价值、可信证据 | 铺垫很长却没有证据 |
| 资讯/行业解读 | 发生了什么（时间+出处）→ 影响谁 → 证据 → 你可以怎么应对 | 时间、出处、反例 | 用旧变化冒充新消息 |
| 知识科普 | 一个可观察的现象 → 为什么 → 概念（先例子后术语）→ 怎么用 | 准确的原理与例子 | 先抛一串抽象名词再逐个解释 |

## 二、段落作用标签（写稿时内部标注，不念出来）

提出问题 / 给答案 / 证据 / 解释原因 / 例子 / 反例或限制 / 处理顾虑 / 行动。

- 相邻两段之间要能说出"所以"或"但是"；说不出就是跳跃，需要补衔接或调换顺序。
- 两段作用相同且没有新增例子、限制或行动 → 合并或删掉。
- 证据紧挨着它支持的判断，不要堆到结尾。

## 三、短视频节奏（60–90 秒参考骨架）

| 段落 | 约占比 | 任务 |
|---|---|---|
| 开头 | 前 1–2 句 | 让目标观众识别问题 + 给出继续看的理由 |
| 承诺/范围 | 1 句 | 这条解决什么（必要时说不解决什么） |
| 主体 | 60–70% | 2–3 个信息点，每点：判断 + 例子/演示 |
| 转折/新信息 | 1 处 | 反例、失败分支、意外但准确的发现 |
| 结尾 | 1–2 句 | 回扣承诺 + 一个最小行动 |

中长视频（3–10 分钟）：问题 → 成品先看 → 章节式过程（每章一个小承诺）→ 验证与排错 → 可复用清单。不要把短视频简单拉长。

## 四、中段防流失

- 每 15–25 秒出现一个新东西：新例子、结果、转折、反例、失败分支。
- 不靠连续反问、"注意了""重点来了"硬撑注意力。
- 先给直观例子，再给术语（面向专业受众时可减少铺垫）。
