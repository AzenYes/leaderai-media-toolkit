# 字幕规范

沿用 `video-rough-cut` 已确认的字幕样式与流程，并针对“人物圆环 + B-roll”做了宽度约束。

## 样式（横版，3840×2160 ASS 设计画布，默认 `--layout landscape`）

| 项目 | 值 |
| --- | --- |
| 字体 | IBM Plex Sans SC SemiBold（ASS 里写内部名 `IBM Plex Sans SC SmBld`，不要写通用家族名再设 Bold）；完整字体文件在 skill 的 `assets/fonts/`，脚本默认使用 |
| 字号 | 192 |
| 字色/描边 | 白字，深色细描边 4.5 |
| 阴影 | 单独一层模糊黑字：`\1a&HB0&`（约 31% 不透明）`\blur8`，偏移 (+6, +8)；主层 Shadow=0 |
| 位置 | 底部、整幅画面水平居中：主层 `\pos(1920,2048)`，阴影层 `\pos(1926,2056)`；不按扣除人像后的区域居中 |
| 行数 | 任一时刻一行：`WrapStyle: 2` + `\q2`，不输出 `\N`；SRT 每条也只有一行 |
| 单行最大宽度 | 2296px（按真实字宽计算）：保证居中字幕右端不碰右下人物圆环；人物全屏时也沿用，风格统一 |

字幕画布改成 1920×1080 时，字号、描边、阴影等比例缩小；保持 3840×2160 画布时交给渲染器缩放，不要再缩一次。

## 竖版样式（`make_subtitles.py --layout vertical`，2160×3840 ASS 画布）

竖版视频发在平台上，底部约 1/4 被作者名、标题、音乐条遮挡，右侧中下部有点赞/评论按钮列，所以字幕不能贴底。

| 项目 | 值 |
| --- | --- |
| 字体/颜色/行数 | 与横版相同 |
| 字号 | 144（约等于 1080 宽画面 72px，手机上清晰且一行能放 10 字左右） |
| 描边/阴影 | 按字号等比：描边 3.4，阴影层 `\blur6`、偏移 (+4.5, +6) |
| 位置 | 字幕底边在距底部约 1/3 处，整幅水平居中：主层 `\pos(1080,2560)`，阴影层 `\pos(1084.5,2566)` |
| 单行最大宽度 | 1560px：右端停在 x≈1860，避开右侧按钮列 |

- 人物圆环在上部一角，与字幕不冲突；B-roll 的字幕带为设计坐标 y 1180–1320，不放关键信息。
- 某个平台的界面遮挡更多、或用户指定了位置时，用 `--pos-y`（字幕底边，ASS 画布像素）和 `--max-width` 覆盖，并在剪辑说明里写明。

## 文本

- 写成片中**实际说出**的话：修正同音错字（如“随手”→“水手”、“说成”→“缩成”、“格林兰”→“格陵兰”）、专有名词、数字。
- 数字用阿拉伯数字（14 倍、400 多年前、60 度、1.8 倍），读起来更快；“一个球”“一张纸”这类量词短语保留汉字。
- 可省略不影响意思的口头填充（“呢”“那”“是吧”）；不能改写观点，不能删限定条件。
- 句内逗号显示为空格，句末标点不显示。

## 断句（make_subtitles.py）

1. 先按句号/问号/感叹号分句，句子之间一定断开。
2. 句内用动态规划在“标点或词边界”上切分，代价规则：
   - 标点处断开：0；词边界断开：4；
   - 下一行以“的/了/呢/吗/吧/着/过/上/里/中”开头：+30；
   - 本行以“的/把/被/从/跟/比/在/对/向/给/让/和/与/是”结尾：+15；
   - 下一行以数字开头（“放大了 | 4 倍”）：+25；
   - 拆开 `terms.txt` 里的保护词：+1000（等于禁止）；
   - 少于 5 个字的孤行：每少 1 字 +2.5；
   - 单行宽度超过上限：不允许。
3. 每条字幕的起止取该行首字、末字在粗剪成片里的真实时间（文本与识别结果做字符级对齐，未匹配的字按前后匹配点插值）；提前 0.06s 出现、延后 0.18s 消失，与下一条间隔 <0.35s 时首尾相接，最短 0.6s。

## 人工复核（每次都做）

逐行读 `字幕_断句检查.txt`：
- 每行能否单独读懂？定语和中心词（“地图上的 | 面积”）、动宾（“放大了 | 4 倍”）、主谓、数字和单位、专有名词、成语有没有被拆开？
- 字/秒 > 9 的行重点回看；对齐率 < 90% 时检查文本是否和实际说话不符。
- 有问题：补 `terms.txt` 或修 `subtitle_text.txt` 后重跑，不要手改 ASS 时间。

## 交付

- `字幕.ass`（保留样式，双层）+ `字幕.srt`（只有正文和时间，不写阴影层）。
- 烧录时从 libass 日志确认 `fontselect` 选中的是 SemiBold，字体缺失要停下处理，不能静默回退。
