# 交付前验收清单

全部通过才交付。发现问题回到对应步骤修复并**从源头重新渲染**。

## 内容与粗剪
- [ ] 文案模式：文案每一句都在，顺序与文案一致；缺失句已在剪辑说明中列出。
- [ ] 成片音轨重新转写后，无重复起句、无半句残留、无“OK 完了”类结束语（`qa_check.py` 的重复短语扫描 + 人工听剪切点）。
- [ ] 数字、单位、否定词、条件词与原话一致。
- [ ] 每个剪切点前后语气连贯，无截字、无爆音。

## B-roll 与人物
- [ ] 分镜表里的每一段都按时出现，动作卡在对应关键词上（抽查联系表与草稿）。
- [ ] 人物圆环出现/回到全屏都是平滑缩放，无黑边、无闪帧；圆环里人脸完整居中。
- [ ] 圆环区域（横版 x>1500 且 y>650；竖版见 `theme.ts` 的 `PIP_KEEPOUT`）没有任何信息被遮挡；字幕与面板、标签不重叠。
- [ ] 竖版：人物圆环在上部一角、位于平台顶部栏下方；字幕底边在距底部约 1/3 处；底部 1/4、右侧按钮列、顶部栏里没有文字或关键图形（可在联系表上叠一层平台界面遮挡框检查）。
- [ ] 画面数据可核实且与口播一致；没有错别字。
- [ ] 每个元素都有入场与出场；段落之间无硬切、无空白帧。
- [ ] 三维/WebGL 画面正常渲染（不是黑屏或空白）。
- [ ] 音效与动作对齐、在人声之下；关键句没有被音效盖住。

## 字幕
- [ ] 断句报告逐行复读通过；保护词检查通过。
- [ ] 字幕与实际说话一致（错字已改）；起止时间不早不晚。
- [ ] 字体实际为 IBM Plex Sans SC SemiBold（看 libass 日志）；没有裁切、没有两行。
- [ ] 抽看最长一行、亮背景（墙面）与暗背景（B-roll）上的字幕都清晰。

## 技术
- [ ] 完整解码无错误；无黑帧（片尾淡出除外）。
- [ ] 分辨率、帧率与原片一致；音视频时长差 < 1 帧。
- [ ] 响度约 -16 LUFS，真峰值 ≤ -1.5 dBTP。
- [ ] 文件名清楚，未覆盖已有文件；SRT/ASS/剪辑说明齐全。
