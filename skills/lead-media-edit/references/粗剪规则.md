# 粗剪规则

依据《口播剪辑技巧深度调研与同事学习手册》（2026-10-16）整理为可执行规则。原则：**内容正确 → 语义顺畅 → 声音舒适**，前一层没解决不做后一层；删除的最小单位首先是“意思”，不是毫秒阈值。

## 1. 一律删除

| 现象 | 判定依据 | 做法 |
| --- | --- | --- |
| 开机/开录等待、结束语（“OK”“完了”“好”） | 首句前、末句后的非叙事声音 | 从首句起音前 ~0.1s 开始，到末句尾音后 ~0.15s 结束 |
| 未完成句（说到一半停下重来） | 短窗复听出现同一句前半段，后面紧跟完整版 | 删前面所有未完成版本，**连同两遍之间的停顿一起删** |
| 短残留起句（只说出一个词就停，如“俄罗斯……俄罗斯也一样”） | 能量岛里 0.3–0.6s 的孤立短岛，紧接着同一词开头的完整句 | 切点移到完整句起音前；**这种 2–4 字残留最容易漏**，每个保留片段的开头都要单独 listen |
| 重复起句（“那我们最常见的呢 / 我们最常见的这种 / 我们最常见的这种地图叫…”） | 同一句开头连续出现 2 次以上 | 只保留最后一次完整说完的版本 |
| 同义重说 | 第二遍没有新增信息 | 保留更清楚、更准确的一遍（不默认最后一遍最好） |
| 口误后纠正（“这个是免费的……不对，基础功能免费”） | 前半句事实被后文修正 | 删错误版本，保留修正后的完整表述 |
| 长时间找词、空白等待 | 无语音或无意义拖音 > ~0.6s，且不在结论后 | 压缩到自然呼吸长度（~0.25–0.4s） |

## 2. 必须保留

- 数字、单位、否定词、条件词（如果/可能/在这个版本里/我这次测试）——它们是信息本身。
- 结论或数字之后的短停顿（给观众处理时间），一般保留 0.3–0.5s。
- 列举不同对象、补充新信息、有意强调的重复。
- 自然、轻微的换气；闭眼听像一个人在自然表达。

## 3. 文案模式（用户提供了口播文案）

1. 把文案按句切开，编号。
2. 对每句，在原片转写 + 短窗复听结果里找出所有出现位置（可能多遍）。
3. 选择保留版本的四个维度，按顺序：①意思和事实正确 ②句子能独立成立（不是半句）③语气与前后接得上 ④动作/视线容易接。
4. 按文案顺序拼接，**不跳句、不调换顺序**。口播里说法与文案略有出入（如“地球是个球”说成“地球它是一个球”）属于正常口语，保留实际说法；字幕写实际说出的话。
5. 文案里有、口播里完全没说的句子：不能补，在剪辑说明中列出“缺失句”，提醒用户补录。
6. 口播里有、文案里没有的内容：有信息量的即兴补充保留并注明；“是吧”“对吧”式自问和自我纠正删掉。

## 4. 技巧模式（没有文案）

1. 先从整段转写写出“这一条要让观众看完能____”。
2. 给每段标用途：问题 / 结论 / 证据 / 步骤 / 例外 / 下一步；找不到用途的段落优先检查是否删除。
3. 不重排段落，除非原顺序明显让人听不懂；移动结论时把条件一起移动，并检查“它/这个/刚才”的指代。
4. 其余按第 1、2 节规则处理。

## 5. 切点

- 用 `speech_islands.py islands` 的能量岛作为真实起止；切点放在两个岛之间的静音中段，避开辅音起音与尾音。
- 低能量不一定可以删（可能是轻声尾字）；切完对剪点前后 3–5 秒单独 `listen` 复核。
- 音频切口两端各做 ~12ms 淡入淡出防爆音；两端都是讲话时不要交叉淡化（会出现叠字）。
- 跳切（同机位删掉中间一段，人物位置突跳）可以直接接受；本 skill 后续会在大部分讲解段落把人物缩成圆环并覆盖 B-roll，跳切会被自然隐藏。全屏段落的跳切若明显，优先换切点或换 take。

## 6. 粗剪验收

- 闭眼听完整粗剪：每句只剩一遍，没有半句、没有截字、语气接得上。
- 只读粗剪转写也能复述问题、答案、限制；没有悬空指代、重复结论。
- `ffprobe` 核对：视频帧数 ≈ 时长 × 原帧率；音视频时长差 < 1 帧。
- 剪辑说明记录：每个保留片段（原片起止 → 成片起止）、每个删除区间及原因、有意保留的重复。
