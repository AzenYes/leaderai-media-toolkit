# B-roll 动效设计规范

目标：像 AE 作品集一样的讲解动画——同一套视觉语言、持续的空间、无缝转场、有节奏的 Motion，每个画面变化都承担解释任务。

## 1. 先写分镜表

| 成片时间 | 口播原句 | 观众要看懂什么 | 画面方案 | 人物 | 音效 |
| --- | --- | --- | --- | --- | --- |
| 0.40–5.00 | 地图上格陵兰…十四倍 | 看起来一样大 vs 真实 14 倍 | 墨卡托世界图，格陵兰/非洲高亮 → 真实大小格陵兰飞入非洲 → 复制到 14 个，计数器 ×14 | 圆环 | whoosh_in / pop / shrink / type / impact |

规则：
- 时间取自**粗剪成片**的逐字时间戳；动作卡在关键词起音（如“十四倍”的“十”）前 0–0.15s。
- 画面变化的触发是**新信息/新步骤/新对比**，不是计时器。没有解释作用的句子（观点、过渡、结尾号召）让人物全屏。
- 一句话同一时刻只突出一个主目标；先让观众知道看哪里，再动作，最后给结果留 ≥0.5s 停留。
- 数字、年份、名称必须可核实，并与口播一致；画面可以比口播更精确（如“400 多年前”配“1569 年”），但不能与口播矛盾。

## 2. 版式与人物占位

### 横版（1920×1080 设计坐标，输出 ×2）

```
┌──────────────────────────────────────────────┐
│ 标题/面板区（左上 110,150 起）     主画面区      │
│                                              │
│            主视觉（中部，x≈500–1450）           │
│                                     ┌─────┐ │
│                                     │人物 │ │  ← 圆环中心(1714,862) r=150
│     字幕带（y>945，居中单行）          └─────┘ │     keepout: x>1500 且 y>650
└──────────────────────────────────────────────┘
```

- 圆环区域不放任何信息；字幕带不放关键信息。
- 主视觉的视觉中心略偏左（x≈900–1000），给右下圆环让位。
- 结尾/全屏段落需要提示卡时，放在人物不在的墙面一侧（如左侧 x 90–540），不遮脸。

### 竖版（1080×1920 设计坐标，输出 ×2 = 2160×3840）

竖版发布在抖音/视频号/小红书/Shorts 等平台，平台界面会盖住画面：顶部约 170px 是状态栏和频道标签，右侧中下部是头像/点赞/评论/分享按钮列，底部约 1/4 是作者名、标题、音乐条。所以人物圆环放**上部一角**，字幕放在**距底部约 1/3 处**。

```
┌───────────────────────┐ 0
│  平台顶部栏（不放信息）   │ 170
│ 标题/要点区     ┌─────┐ │
│ (x 60–680)     │人物 │ │ ← 圆环中心(880,360) r=150（默认右上）
│                └─────┘ │   keepout: x 700–1080, y 170–540
│                        │ 560
│    主视觉区             │
│    （x 60–940，        │
│     y 560–1160）    ┆按│ 860
│                    ┆钮│
│  字幕带（底边 y≈1280）┆列│ 1180–1320
│                    ┆  │ 1440
│  平台底部信息区：作者名/  │
│  标题/音乐（只放背景）    │
└───────────────────────┘ 1920
```

- `project.ts` 设 `ORIENTATION = "vertical"`；`PIP_CORNER` 默认 `"tr"`（右上）。原片人物明显偏右、或主视觉需要右侧空间时改 `"tl"`（左上，中心 (200, 360)），标题区随之换到右侧。
- 场景布局用 `theme.ts` 的 `W/H/PIP/PIP_KEEPOUT/SUB_BAND/PLATFORM_UI`，不要写死坐标。
- 主信息放中部 y≈560–1160，宽度控制在 x 60–940；圆环旁的上部空位放标题/要点。
- 底部 1/4（y>1440）、右侧按钮列（x>940、y≈860–1640）、顶部栏（y<170）只放背景与装饰，不放文字、数字、关键图形。
- 竖屏信息要比横版更少、更大：同一时刻一个主视觉 + 一句短标签；字号下限沿用（标签 ≥24、正文 ≥28，1080 宽设计稿），标题建议 ≥56。
- 横版素材做竖版发布时，不要直接拉伸；按竖版画布重新排版 B-roll，人物取景用 `FACE` 重新标定。

## 3. 人物圆环（engine/Presenter.tsx）

- 状态 0=全屏、1=圆环；切换 0.62s `inOutQuint`。缩放用对数插值，人物头肩锚点 `FACE` 从原位置平移到圆心，圆形 `clip-path` 半径从 1400 收到 150——人物“缩进”圆环，B-roll 从四周显露，无硬切。
- 圆环：纸色 3px 细环 + 琥珀色旋转弧段 + 柔和落影；内侧轻微压暗与深色背景融合。
- `FACE`：抽帧确认人物头肩中心与半径（通常头顶到胸口，坐标按当前画幅的设计画布）；人物大幅移动时分段设置。
- 全屏段落缓慢推近 1.0→1.045，避免静止。

## 4. 运动语言

| 用途 | 做法 | 缓动 |
| --- | --- | --- |
| 摄像机移动 | 关键帧之间缩放取对数插值、中心线性插值 | inOutQuint |
| 文字出现 | 遮罩内上推（Reveal），层级错开 0.08–0.15s | outQuart |
| 面板/卡片 | 位移 40px + 透明度，出场更快 | outCubic / inCubic |
| 标签 | 圆点 → 引线生长 → 文字卡片 | outCubic |
| 图形出现 | 从 0.4 缩放弹出 | outBack |
| 数字 | 跟随动画进度滚动（tabular-nums） | 与动画同步 |
| 指针/罗盘 | 过冲后稳定 | outElastic |
| 重点落点 | 1.12 倍回弹 + impact | outCubic |

- 每个元素都有入场和出场；出场比入场快（约 0.3–0.4s）。
- 连续讲解放在**同一个持续舞台**（如一张世界地图），用摄像机在段落间移动；三维→二维等媒介切换时让几何完全对齐再交叉淡化 0.3–0.4s。
- 底图要无缝：地图左右平铺，避免露出边缘；背景统一径向渐变 + 胶片颗粒 + 暗角。

## 5. 视觉系统

- 一条视频只用一套配色：深色底 + 纸色文字 + 2–3 个强调色，并给强调色固定语义（例：琥珀=地图上的样子，青绿=真实大小，珊瑚=对比对象/警示）。
- 字体：标题 Noto Serif SC 900；说明与标签 IBM Plex Sans SC 500/600；数字 Inter 600。全部本地加载并子集化。
- 字号下限：标签 ≥24px、正文 ≥28px（1080 设计稿）；手机上要读得清。

## 6. 音效（scripts/sfx_synth.py 程序化生成）

| 动作 | 音效 | 建议音量 |
| --- | --- | --- |
| 人物缩成圆环 / 回到全屏 | whoosh_in / whoosh_out | 0.26–0.30 |
| 摄像机大移动 | whoosh_in / swish | 0.15–0.22 |
| 标签、图形出现 | pop / pop_low | 0.18–0.24 |
| 连续计数、逐格点亮、刻度 | tick / type | 0.16–0.26 |
| 鼠标抓取/松开 | click | 0.28–0.34 |
| 拖动、画线 | drag | 0.18–0.26 |
| 缩小、真实尺寸揭示 | shrink | 0.22–0.28 |
| 拉伸、变形 | stretch | 0.18–0.22 |
| 标题出现 | glide | 0.13–0.22 |
| 结论落点 | impact / chime | 0.24–0.34 |
| 剥开、撕开 | peel | 0.30 |

- 音效始终在人声之下，关键数字和限定条件处不叠响亮音效。
- 不默认加背景音乐（教学类视频加音乐可能干扰理解）；用户要求时再加，并在人声处闪避。

## 7. 技术要点（Remotion）

- 所有动画由 `useCurrentFrame()` 驱动，禁止 CSS transition/animation。
- 时间工具 `engine/ease.ts`：`ramp / env / keyed` 都以秒为单位，直接对齐字时间。
- 三维用 `@remotion/three` 的 `ThreeCanvas`，正交相机与设计画布（横版 1920×1080 / 竖版 1080×1920）像素一一对应，方便与 SVG 层对齐；渲染加 `--gl=angle`。
- 人物视频用 `OffthreadVideo`（静音），人声单独用处理后的 `voice.wav`。
- 只在需要时渲染 B-roll（人物全屏时跳过），节省渲染时间。
- 地理类：d3-geo + topojson；“真实大小”移动用球面旋转（`movedProjection`），不是平面缩放。
